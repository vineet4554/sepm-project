# Software Requirements Specification (SRS)
## 1. Introduction
This system is designed to manage users within an organization. It allows registration, login, and dashboard viewing.
## 2. Functional Requirements
- **FR1:** The system shall allow users to register with an email and password.
- **FR2:** The system shall authenticate users using JWT.
- **FR3:** The system shall provide a dashboard to view user statistics.
## 3. Non-Functional Requirements
- **NFR1:** The application must respond within 500ms.
